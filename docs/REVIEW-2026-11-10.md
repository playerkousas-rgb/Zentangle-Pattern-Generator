## 6. 未做／限制／建議

### 6.1 DCT 隱形水印（W2）— v1.2.0 已完成

- **為何未做**：`templates/watermark` 的 codec 要在 canvas 像素做 DCT 嵌入，屬另一條產品線
  （DRAWSCOUT）；本 app 輸出係「圖案化作品」，加水印會改變筆觸觀感，需先同你確認品牌做法。
- **現時補償**：PNG `tEXt` 寫入 `Copyright`／`Software`／`Source`（可被 exiftool 讀到）＋
  頁尾與列印頁腳可見版權。
- **建議**：如要跟足 W2，直接引入 `templates/watermark/scout_watermark_codec_v1.0.mjs`，
  在 `toPNGBlob()` 後對 ImageData 嵌入 v1 payload（`DRAWSCOUT|v1`），並用解碼器回歸一次。

### 6.2 Tailwind CDN → 建置期編譯（S7＋效能）— v1.2.0 已完成

- 現況：`cdn.tailwindcss.com` 係 runtime JIT，約 400 KB、會 block render、生產環境 console
  有官方警告「should not be used in production」。
- 但 README 已定案「唔要兩套並存、要一次改完＋完整視覺回歸」。本環境冇瀏覽器做視覺回歸，
  **刻意唔動**。
- 建議做法：`npm i -D tailwindcss @tailwindcss/vite`，把 class 掃描範圍限定 `index.html`，
  產出一個 `~/assets/app.css`（估計 15–25 KB gzip 5 KB），刪 CDN script，逐頁對比 390／768／1440。

### 6.3 建議：Vercel 設定微調（5 分鐘）

```jsonc
// vercel.json 建議加（唔影響現有行為）
"regions": ["hkg1"],                       // 香港讀者為主，函數／邊緣就近
"headers": [
  { "source": "/icons/(.*)", "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }] },
  { "source": "/(.*)", "headers": [
      { "key": "X-Content-Type-Options", "value": "nosniff" },
      { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" },
      { "key": "Permissions-Policy", "value": "camera=(self), microphone=(), geolocation=()" }
  ]}
]
```
> ⚠️ 唔好加 `X-Frame-Options: DENY` 或嚴格 `frame-ancestors`：Arena 的 Live Preview 係用 iframe
> 嵌入，加咗會直接白畫面。CSP 亦要為 Tailwind CDN 開 `unsafe-inline`／`unsafe-eval`，
> 現階段唔值。

2. **45 個圖案 SVG 過 SVGO**（30 分鐘）：現時 `public/patterns` 397 KB，估計可減 30–50%。
