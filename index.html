❓ 禪繞畫新手指南

咩係禪繞畫？

禪繞畫（Zentangle®）由 Rick Roberts 同 Maria Thomas 創立：用最簡單嘅點、線、面，一筆一筆畫出結構化圖案。過程專注、放鬆，而且冇嘢係「錯」——官方文化甚至唔用橡皮擦，所有意外筆觸都可以變成圖案嘅一部分。

傳統五步（本工具已代你做咗一半）

1. 感恩放鬆 — 深呼吸，當作冥想時間
2. 點四角 — 喺紙上點四個角 + 畫邊框
3. 畫串線 String — 隨手畫幾條線將畫面分格（= 本工具嘅「分區」）
4. 填圖案 Tangle — 每一格填一種重複圖案（= 本工具自動幫你填）
5. 陰影 + 簽名 — 鉛筆加陰影，簽名欣賞

名詞小字典

畫磚 Tile — 官方標準 89mm 正方形畫紙
串線 String — 分格線，通常鉛筆畫、好淡
圖案 Tangle — 重複結構嘅花紋，全世界有過千款
Zendala — 圓形畫磚，曼陀羅風格
Bijou — 51mm 細畫磚
Monotangle — 成幅只用一種圖案嘅作品
